# LinkedIn project description — draft

**Unified Health | Wearable Health Technology — Business Analysis & Product Strategy**

Developed a business analysis case study for a proposed cross-platform wearable-health companion. The project explores how permissioned data from compatible smartwatch and smart-ring ecosystems could be organized into a source-transparent view of personal activity, sleep and wellness trends.

The case study includes competitor and integration research, a proposed MVP scope, functional requirements and acceptance criteria, customer journey and system data-flow diagrams, a conceptual relational data model, and a MySQL schema/query starter. It also defines a public-data analysis approach using a historical Fitbit dataset and documents the sample's limitations.

**Skills and tools represented:** Business analysis, requirements documentation, process mapping, SQL / MySQL, Excel, Tableau planning, Jira backlog design, Confluence project documentation, product strategy and data governance.

**Project note:** This is a proposed product and a work-in-progress portfolio case study, not a launched app. The SQL schema and queries are prepared but must still be executed against imported data; the Tableau dashboard and live Jira/Confluence workspaces are not yet complete.
