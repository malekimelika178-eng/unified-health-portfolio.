# Publish your portfolio — simplest route

The site is prepared. To get a public link you can put on LinkedIn, you need to publish it under an account you control. I cannot sign into or publish to your GitHub account from this chat.

## GitHub Pages (free)

1. Sign in at https://github.com/ (create a free account if needed).
2. Click **New repository**.
3. Name it `unified-health-portfolio` and choose **Public**.
4. Create the repository.
5. On the repository page, choose **Add file → Upload files**.
6. Unzip `unified_health_business_analyst_portfolio.zip` on your Mac.
7. Open the unzipped `unified-health-portfolio` folder and upload its contents (including `index.html` and all folders) to the repository root.
8. Commit the upload.
9. Open **Settings → Pages**.
10. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, Folder to **/(root)**, then Save.
11. GitHub will show the public site URL after deployment. It will look like `https://YOUR-USERNAME.github.io/unified-health-portfolio/`.

## Before sharing publicly

- Review the status section on `index.html`; it intentionally states what is drafted and what is not yet executed.
- Remove any draft numerical research claims that you have not personally verified.
- Do not upload private health data, API keys, OAuth tokens or personal information.
- Keep only public, aggregated, licensed or appropriately anonymized material in the repository.

## Optional alternative: Notion

You can create a public Notion page and paste the project overview from `index.html` or `business-analysis/PROJECT_BRIEF.md`. Use GitHub for the SQL and diagram files; link to those from Notion.
